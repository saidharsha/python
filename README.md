# 🎙️ Voice Assistant (Python)

A simple voice assistant that recognizes voice commands and performs actions like opening applications, telling the time, and searching Google.

## 🚀 Features
- Voice command recognition
- Text-to-speech response
- Opens websites and performs basic tasks

## 🧩 Tech Stack
- **Language:** Python  
- **Libraries:** SpeechRecognition, pyttsx3, datetime, webbrowser  

## ⚙️ How to Run
```bash
pip install SpeechRecognition pyttsx3
python main.py
